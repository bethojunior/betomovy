# Mobilidade-Site

## Pré-requisitos

Antes de iniciar, certifique-se de ter o **PHP na versão 7.4** instalados em sua máquina.

## Rodando

1. Criar o arquivo `.env` com base no `.env.example`

```
cp .env.example .env
```

2. Iniciar o servidor
```
php -S localhost:8000 -t public
```

3. Acesse a aplicação
```
http://localhost:8000
```

## Observações

O arquivo `.env` é essencial para o funcionamento do projeto, garantindo que as configurações corretas sejam aplicadas.
